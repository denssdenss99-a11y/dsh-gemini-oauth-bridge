# Инструкция по установке dsh-gemini-oauth-bridge на другой компьютер

Этот плагин позволяет подключить подписку Google Gemini (через OAuth-авторизацию Antigravity / Google Code Assist) в DeepSeek Harness (DSH) как локального OpenAI-совместимого провайдера с поддержкой рассуждений (Reasoning Effort), Vision (загрузка картинок) и генерации изображений.

---

## Вариант 1: Быстрая установка через dsh CLI

1. Распакуйте папку `dsh-gemini-oauth-bridge` в удобное место на новом компьютере.
2. В терминале перейдите в профиль DSH или установите плагин командой:
   ```bash
   dsh plugin --profile web add /путь/к/папке/dsh-gemini-oauth-bridge
   ```
3. Запустите DSH Web:
   ```bash
   dsh web
   ```
4. В браузере перейдите в **Настройки → Gemini OAuth** и нажмите **Войти через Google**.

---

## Вариант 2: Ручная установка в профиль Web

1. Скопируйте папку `dsh-gemini-oauth-bridge` в:
   ```bash
   ~/.dsh/profiles/web/node_modules/dsh-gemini-oauth-bridge
   ```
2. В файле `~/.dsh/profiles/web/cordis.patch.yml` добавьте строку активации плагина:
   ```yaml
   - insert:
       - id: gemini-oauth-bridge
         name: 'dsh-gemini-oauth-bridge'
   ```
3. Запустите DSH:
   ```bash
   npx @deepseek-ai/dsh web
   ```
4. Откройте интерфейс DSH в браузере, перейдите в **Настройки (Settings) → Gemini OAuth** и авторизуйтесь в своем Google-аккаунте.

---

## Особенности сборки и внесенные улучшения

- **Русский язык:** Интерфейс плагина и страницы статуса полностью переведены на русский язык.
- **Поддержка Effort (Рассуждения):** Ползунок Effort (Low / Medium / High / Max) динамически управляет версией модели. Внедрен скрытый системный промпт, чтобы модель честно и без галлюцинаций сообщала свой текущий уровень рассуждений.
- **Vision (Загрузка изображений):** Для всех моделей прописан флаг `input: [text, image]`. Вы можете загружать изображения в чат, и модели их распознают.
- **Генерация изображений:** Добавлена модель `gemini-3.1-flash-image`. Сгенерированные изображения автоматически сохраняются и отдаются в чат DSH через локальный HTTP-эндпоинт без блокировок CSP браузера.
- **Защита от переполнения контекста:** Настроен размер окна в 2 000 000 токенов, а также добавлен автоматический фильтр, вырезающий тяжелые Base64-строки из входящей истории переписки.
- **Чистый список моделей:** В UI отображаются только актуальные модели текущего поколения:
  - `gemini-3.8-flash`
  - `gemini-3.1-pro`
  - `gemini-3.7-flash`
  - `gemini-2.5-flash`
  - `gemini-3.1-flash-image`
